# 文件索引

本目錄收錄 mini計算機的技術與使用文件。若第一次接觸本專案，建議依下列順序閱讀。

| 文件 | 內容 | 適合對象 |
| --- | --- | --- |
| [使用指南](USER_GUIDE.md) | 安裝、操作、模式、鍵盤、運算式語法與疑難排解 | 一般使用者 |
| [系統架構與技術文件](ARCHITECTURE.md) | 分層架構、服務職責、資料流、儲存、主題、日誌與擴充方式 | 開發者 |
| [系統設計文件](DESIGN.md) | 需求、畫面設計、狀態模型、錯誤處理、測試與發佈設計 | 開發者、維護者 |
| [建置與發佈](BUILD_AND_RELEASE.md) | 建置、測試、x64／ARM64 發佈、Release 檢查清單 | 開發者、發佈者 |
| [隱私說明](PRIVACY.md) | 本機資料、日誌、剪貼簿與網路行為 | 使用者、審查者 |
| [開發紀錄](DEV_LOG.md) | 各版本目標、變更、問題與待辦 | 維護者 |

其他根目錄文件：

- [README](../README.md)：專案簡介、下載與快速開始
- [CHANGELOG](../CHANGELOG.md)：版本異動
- [RELEASE_NOTES](../RELEASE_NOTES.md)：給使用者的發行說明
- [CONTRIBUTING](../CONTRIBUTING.md)：貢獻流程
- [SECURITY](../SECURITY.md)：安全性政策
- [LICENSE](../LICENSE)：MIT License

## 文件維護原則

- 功能或行為變更時，同步更新使用指南與相關技術文件。
- 每次開發工作更新 `DEV_LOG.md`，不要事後補寫。
- 文件中的指令與路徑需可直接執行，避免只描述概念。
- 使用者可見文案以繁體中文為主。
