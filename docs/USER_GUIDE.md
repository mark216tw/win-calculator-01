# 使用指南

本文件說明 mini計算機的下載、操作方式、運算式語法與常見問題。適用版本 1.6.0。

## 1. 系統需求

- Windows 11（build 22000 以上）
- x64 或 ARM64 架構
- [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0)（非 Self-Contained 版本必備）

## 2. 下載與啟動

1. 開啟 [最新發行版本](https://github.com/mark216tw/win-calculator-01/releases/latest)。
2. 依裝置架構下載：
   - x64 電腦：`MiniCalculator-1.5.1-win-x64.zip`
   - Windows on ARM：`MiniCalculator-1.5.1-win-arm64.zip`
3. 解壓縮到任何可寫入位置。
4. 執行 `MiniCalculator.exe`。

本專案不提供安裝程式，也不提供 Self-Contained 版本；若未安裝 .NET 10 Desktop Runtime，啟動時會顯示缺少執行階段的訊息。

## 3. 主畫面

主畫面上方由左至右為：

- 應用程式名稱
- 「標準」／「科學」模式切換
- 視窗置頂按鈕
- 歷史紀錄按鈕
- 設定按鈕

下方為顯示區與鍵盤：

- **運算式列**：可直接編輯，支援滑鼠選取與游標移動。
- **結果列**：即時預覽計算結果；按 `=` 後成為正式結果並寫入歷史。
- **複製按鈕**：可複製格式化結果（含千分位）或原始值（不含千分位）。
- **狀態訊息**：例如記憶體為空、已複製等提示。

### 極小視窗模式

極小視窗模式適合需要一直放在畫面上、又不想佔用太多空間的情境。

- 僅限標準模式使用；科學模式不會顯示極小模式按鈕。
- 按右上角極小模式按鈕或 `Ctrl+M` 進入。
- 只保留顯示區、`0`–`9`、`.`、`+` `−` `×` `÷`、`=`、`C`、`⌫`。
- 預設視窗 230×300，可縮到最小 190×250；版面與按鍵會隨視窗大小精簡。
- 進入時會自動置頂；仍可在極小工具列手動取消置頂。
- 「返回標準模式」或關閉程式時，會還原進入前的置頂設定。
- 極小模式只能返回完整標準模式，不會直接切換到科學模式。
- 完整視窗與極小視窗分別記住位置與大小；下次啟動仍固定顯示完整視窗。

## 4. 標準模式

標準模式適合日常計算。

| 按鍵 | 說明 |
| --- | --- |
| `0`–`9`、`.` | 輸入數字與小數點 |
| `+` `−` `×` `÷` | 四則運算 |
| `=` | 計算結果；連按可重複上次運算 |
| `%` | 將數值除以 100 |
| `1/x` | 倒數 |
| `x²` | 平方 |
| `√` | 平方根 |
| `±` | 正負號切換 |
| `C` | 全部清除 |
| `CE` | 只清除結尾數字 |
| `⌫` | 刪除前一個字元 |
| `MC` `MR` `M+` `M−` `MS` | 單槽記憶體操作 |

標準模式可用實體鍵盤輸入括號，畫面不另外提供括號鍵。

## 5. 科學模式

科學模式在標準模式之外提供更多函式與常數。

### 角度單位

按 `DEG`／`RAD`／`GRAD` 按鈕循環切換。角度單位會影響 `sin`、`cos`、`tan`、`asin`、`acos`、`atan`。

### 2nd 與 hyp

- `2nd`：切換三角函式的反函式（`sin⁻¹`、`cos⁻¹`、`tan⁻¹`）。
- `hyp`：切換雙曲函式（`sinh`、`cosh`、`tanh`）。
- 兩者同時開啟時為反雙曲函式（`sinh⁻¹`、`cosh⁻¹`、`tanh⁻¹`）。

### 函式與運算

| 類型 | 功能 |
| --- | --- |
| 對數／指數 | `ln`、`log`、`log₂`、`eˣ`、`10ˣ` |
| 次方／根 | `xʸ`、`x²`、`x³`、`√`、`∛` |
| 其他 | `n!`、`mod`、`|x|`、`floor`、`ceil`、`round` |
| 常數／隨機 | `π`、`e`、`rand()` |
| 角度換算 | `DMS`、`deg()` |
| 顯示 | `F-E` 科學記號 |

### 科學記號

`F-E` 會切換結果的科學記號顯示。狀態會保存，下次啟動仍維持。

## 6. 記憶體

本程式提供單槽記憶體，標準與科學模式共用。

| 按鍵 | 說明 |
| --- | --- |
| `MS` | 將目前結果存入記憶體 |
| `MR` | 取出記憶體值並插入運算式 |
| `M+` | 將目前結果加到記憶體 |
| `M−` | 將目前結果從記憶體減去 |
| `MC` | 清除記憶體 |

記憶體值會保存在設定檔中，重新啟動後仍可使用。記憶體為空時按 `MR` 會顯示提示，不會標示為錯誤。

## 7. 歷史紀錄

- 按右上角歷史按鈕或 `Ctrl+H` 開啟。
- 每筆紀錄包含運算式、結果與時間。
- 雙擊項目或選取後按 `Enter` 可回填至主畫面。
- 按 `Esc` 關閉視窗。
- 按「清除」會先顯示二次確認。
- 最多保留 100 筆，超過時移除最舊紀錄。

## 8. 設定

按右上角設定按鈕或 `Ctrl+,` 開啟。

### 顯示模式

- **跟隨系統**：依 Windows 淺色／深色設定自動切換。
- **淺色**：固定淺色。
- **深色**：固定深色。

### 主題色

提供 12 款主題色，每款皆支援淺色與深色：

經典藍、護眼黃、森林綠、暮色紫、中性灰、玫瑰粉、青碧、夕陽橘、靛青、珊瑚紅、薰衣草、暖棕。

### 其他設定

- **視窗置頂**：主畫面右上角釘選按鈕。
- **恢復預設值**：將顯示模式、主題、置頂、角度單位、記憶體、模式與科學記號恢復為預設，操作前會二次確認。
- **關於資訊**：版本、檔案版本、授權與隱私說明位於設定頁底部。

## 9. 剪貼簿

- 複製格式化結果：保留千分位，例如 `1,234.5`。
- 複製原始值：移除千分位，適合貼到其他程式或算式，例如 `1234.5`。
- 複製成功後會顯示短暫的「已複製」提示。
- 快捷鍵 `Ctrl+Shift+C` 可複製格式化結果。

## 10. 鍵盤操作

| 按鍵 | 功能 |
| --- | --- |
| `0`–`9`、`.` | 輸入數字 |
| `+` `-` `*` `/` `^` `%` `(` `)` | 運算子與括號 |
| `Enter` | 計算；連按可重複上次運算 |
| `Esc` | 全部清除 |
| `Backspace` | 刪除前一個字元 |
| `Ctrl+H` | 歷史紀錄 |
| `Ctrl+,` | 設定 |
| `Ctrl+1` | 標準模式 |
| `Ctrl+2` | 科學模式 |
| `Ctrl+M` | 切換極小／完整視窗（僅標準模式） |
| `Ctrl+Shift+C` | 複製格式化結果 |
| 方向鍵 / `Home` / `End` | 移動輸入游標 |

也可直接輸入函式名稱，例如 `sin(30)`、`ln(2)`、`sqrt(9)`、`10 mod 3`、`5!`、`π`、`e`、`rand()`。

## 11. 運算式語法

### 基本規則

- 支援 `+`、`-`、`*`、`/`、`^`、`%`、`!`、`mod`。
- 支援括號與運算子優先序。
- 缺少右括號時，計算前會自動補齊。
- 空白字元會被忽略。
- 支援 `×`、`÷`、`−` 等顯示符號，求值時會正規化。

### 隱含乘法

相鄰的值可省略乘號：

```text
2π        = 6.283185307179586
2(3+4)    = 14
3sin(30)  = 1.5（DEG）
2e        = 5.43656365691809
```

`2e3` 會視為科學記號，不會拆成 `2 × e × 3`。

### 百分比

`%` 代表除以 100：

```text
200*10%   = 20
50%       = 0.5
```

### 階乘

```text
5!        = 120
```

階乘僅接受非負整數，超過 170 會回報溢位。

### 度分秒

- `dms(x)`：十進位度轉度分秒數值，格式為 `d.mmss`。
- `deg(x)`：度分秒數值轉十進位度。

```text
dms(12.5) = 12.3
deg(12.3) = 12.5
```

### 連按等號

按 `=` 後再按 `=`，會以最右側頂層運算子重複運算：

```text
2+3=      → 5
=         → 8
=         → 11
```

支援 `+`、`−`、`×`、`÷`、`^`、`mod`。函式與後置運算（例如 `5!`、`50%`）不會重複。

### 函式清單

`sin`、`cos`、`tan`、`asin`、`acos`、`atan`、`sinh`、`cosh`、`tanh`、`asinh`、`acosh`、`atanh`、`ln`、`log`、`log2`、`exp`、`sqrt`、`cbrt`、`abs`、`floor`、`ceil`、`round`、`dms`、`deg`、`rand`。

函式名稱不分大小寫。函式需使用括號，例如 `sin(30)`。

## 12. 視窗行為

- 關閉主視窗即完整結束程式，不會常駐系統匣。
- 再次啟動時只會有一個實例；第二次啟動會帶回既有視窗。
- 視窗大小、位置與最大化狀態會保存。
- 極小視窗與完整視窗分別保存位置與大小；啟動固定顯示完整視窗。
- 還原位置時會檢查目前螢幕工作區，避免視窗出現在螢幕外或工作列下方。

## 13. 資料位置與隱私

| 資料 | 路徑 |
| --- | --- |
| 設定 | `%AppData%\MiniCalculator\settings.json` |
| 歷史紀錄 | `%AppData%\MiniCalculator\history.json` |
| 日誌 | `%AppData%\MiniCalculator\logs\app-yyyyMMdd.log` |

程式不具備網路功能，不會收集或傳送資料。詳見[隱私說明](PRIVACY.md)。

若要完全重設，可先關閉程式，再刪除 `%AppData%\MiniCalculator` 資料夾。

## 14. 疑難排解

### 無法啟動，顯示缺少 .NET

請安裝 [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0)，並確認安裝的架構與下載檔一致（x64 或 ARM64）。

### SmartScreen 警告

未簽章的執行檔可能觸發 SmartScreen。請確認檔案來自本專案 Releases，再選擇「仍要執行」。

### 設定或主題沒有套用

請確認使用的是目前版本，並嘗試在設定頁重新選擇顯示模式與主題。若仍無效，可刪除 `settings.json` 後重新啟動。

### 歷史紀錄沒有出現

歷史紀錄會在第一次開啟歷史視窗或第一次新增紀錄時載入。若檔案不存在，會自動建立。

### 按鍵沒有反應

請確認輸入焦點在運算式列；可先以滑鼠點擊運算式列，或按 `Ctrl+1`／`Ctrl+2` 重新切換模式。

## 15. 無障礙

- 可點擊元素具備螢幕閱讀器名稱。
- 圖示按鈕提供 ToolTip。
- 鍵盤 Tab 移動時有可見焦點框。
- 錯誤訊息會以固定字級顯示，避免畫面高度跳動。

## 16. 已知限制

- `CE` 只處理結尾數字；科學記號結尾（例如 `1E+5`）會直接全部清除。
- 連按 `=` 僅支援最右側頂層數值運算，函式與後置運算不重複。
- 標準模式畫面未提供括號按鈕，需使用鍵盤輸入。
- 尚未提供 MSIX 安裝封裝。
- 部分原生控制項外觀仍依系統呈現，未完全套用主題。
