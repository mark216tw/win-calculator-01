# 隱私說明

mini計算機（以下稱「本程式」）以離線、單機使用為設計原則。本文件說明本程式會存取哪些資料、存放位置與用途。

## 1. 摘要

- 本程式**不具備網路功能**，不會連線到任何伺服器。
- 不收集、不上傳、不販售任何個人資料。
- 不需要帳號、不需要登入。
- 所有設定、歷史紀錄與日誌僅存放於目前使用者的本機 `%AppData%`。
- 移除程式或刪除資料夾即可清除本程式產生的資料。

## 2. 本機資料

| 資料 | 路徑 | 用途 |
| --- | --- | --- |
| 設定 | `%AppData%\MiniCalculator\settings.json` | 顯示模式、主題、置頂、角度單位、記憶體、上次模式、科學記號、視窗位置與大小 |
| 歷史紀錄 | `%AppData%\MiniCalculator\history.json` | 最近 100 筆計算的運算式、結果與時間 |
| 日誌 | `%AppData%\MiniCalculator\logs\app-yyyyMMdd.log` | 警告與錯誤記錄，供疑難排解 |

### 設定

包含使用者偏好與視窗狀態。這些資料只在本機讀寫，不會離開裝置。

### 歷史紀錄

保存最近 100 筆計算結果，方便回填。若使用的運算式包含敏感資訊，請自行清除歷史紀錄或刪除 `history.json`。

### 日誌

僅記錄 Warning 以上事件與例外摘要，不記錄完整運算式內容。日誌會依日期建立，可自行刪除。

## 3. 剪貼簿

- 只有在使用者按下複製按鈕或 `Ctrl+Shift+C` 時，本程式才會將結果寫入 Windows 剪貼簿。
- 本程式不會讀取剪貼簿內容。
- 剪貼簿內容由 Windows 與其他應用程式管理，請自行注意敏感資訊。

## 4. 網路與遙測

- 本程式沒有網路程式碼，不會傳送遙測、分析或當機報告。
- 不會檢查更新，也不會下載遠端資源。
- 相依套件僅在本機載入。

## 5. 系統資訊存取

本程式會存取下列 Windows 功能：

| 功能 | 用途 |
| --- | --- |
| 登錄檔 `HKCU\...\Themes\Personalize` | 讀取系統淺色／深色設定 |
| `SystemEvents.UserPreferenceChanged` | 系統主題變更時更新畫面 |
| Mutex／EventWaitHandle | 單一實例與第二次啟動通知 |
| `%AppData%` 檔案系統 | 儲存設定、歷史與日誌 |
| Windows 剪貼簿 | 使用者主動複製結果時寫入 |
| 螢幕工作區資訊 | 還原視窗位置時避免超出畫面 |

上述存取皆為本機行為，不會將資料傳送至外部。

## 6. 資料保留與刪除

- 設定與歷史會保留到使用者刪除為止。
- 日誌依日期累積，不會自動清除。
- 若要完整清除本程式資料：
  1. 關閉本程式。
  2. 刪除 `%AppData%\MiniCalculator` 資料夾。
  3. 視需要清除 Windows 剪貼簿。

## 7. 兒童與敏感資料

本程式為一般用途計算機，不針對兒童設計，也不會主動蒐集任何個人資料。若使用者輸入敏感數值，相關內容可能暫存於本機歷史紀錄，請自行管理。

## 8. 第三方元件

本程式使用下列開源元件，皆於本機執行：

- CommunityToolkit.Mvvm
- Microsoft.Extensions.Hosting / DependencyInjection / Logging
- xUnit（僅測試）

各元件依其原授權條款提供，不涉及資料傳輸。

## 9. 政策變更

若未來版本新增網路或資料處理功能，將同步更新本文件與 `RELEASE_NOTES.md`。
